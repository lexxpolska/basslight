# Basslight Production — сайт компании

Статический сайт на чистых HTML5 + CSS3 + vanilla JavaScript. Без сборщиков, без npm, без бэкенда. Открывается двойным кликом по `index.html` или заливается на любой хостинг как есть.

## Структура проекта

```
/
├── index.html                  — Главная
├── rental.html                 — Аренда оборудования (каталог-хаб)
├── rental-sound.html           — Аренда: звук
├── rental-light.html           — Аренда: свет
├── rental-fx.html              — Аренда: спецэффекты
├── rental-stage.html           — Аренда: сцена, конструкции, мебель
├── rental-media.html           — Аренда: мультимедиа и интерактив
├── sale.html                   — Продажа оборудования
├── china.html                  — Оборудование из Китая под заказ
├── services.html               — Техническое сопровождение мероприятий
├── staff.html                  — Услуги персонала
├── cases.html                  — Кейсы / портфолио
├── about.html                  — О компании
├── faq.html                    — Вопросы и ответы
├── contacts.html                — Контакты и заявка
├── privacy.html                — Политика обработки персональных данных
├── 404.html                    — Страница «не найдено»
├── assets/
│   ├── css/style.css           — вся дизайн-система одним файлом
│   ├── js/main.js              — вся логика одним файлом
│   ├── img/                    — SVG-заглушки изображений
│   └── docs/                   — сюда кладутся PDF (договоры, инструкции)
├── sitemap.xml
├── robots.txt
├── netlify.toml
└── .github/workflows/deploy.yml
```

Каждая страница — самостоятельный HTML-файл с одинаковой шапкой, мобильным меню, плавающей кнопкой связи и подвалом. Все пути в коде — **относительные** (`assets/css/style.css`, `rental.html` и т.д.), без ведущего слэша, поэтому сайт одинаково работает и в корне домена, и в подпапке (например, `https://site.by/basslight/`).

## Как редактировать тексты и телефоны

Все тексты — обычный HTML, открывайте нужный `.html`-файл в любом редакторе и правьте. Телефоны и ссылки на Telegram/WhatsApp встречаются в трёх местах на каждой странице (шапка, мобильное меню, подвал) плюс в плавающей кнопке связи — при замене номеров ищите по всему файлу (Ctrl+F / Cmd+F) строку `+375291305549` (Алексей) и `+375291034679` (Дмитрий) и меняйте везде одинаково.

Способ отправки формы заявки переключается одной строкой в начале файла `assets/js/main.js`:

```js
const MODE = 'telegram'; // 'formspree' | 'telegram'
const FORM_ENDPOINT = 'https://formspree.io/f/YOUR_FORM_ID';
```

- `'telegram'` — работает сразу, без каких-либо настроек: после отправки формы открывается чат в Telegram с готовым текстом заявки. Подходит, если пока нет своего сервера форм.
- `'formspree'` — заявки уходят на email/в кабинет через сервис [Formspree](https://formspree.io/). Нужно зарегистрироваться на formspree.io, создать форму и вставить её адрес в `FORM_ENDPOINT` вместо `YOUR_FORM_ID`.

## Как заменить логотип

Логотип лежит в `assets/img/logo.svg` — отдельным файлом, подключается тегом `<img src="assets/img/logo.svg">` в шапке, мобильном меню и подвале каждой страницы. Чтобы заменить:

1. Подготовьте новый логотип в формате SVG (лучше всего) или PNG с прозрачным фоном.
2. Если это SVG — просто перезапишите файл `assets/img/logo.svg`, сохранив пропорции примерно 340×64 (широкий горизонтальный логотип), чтобы не «прыгала» вёрстка.
3. Если это PNG/JPG — сохраните его как `assets/img/logo.png` и замените во всех HTML-файлах атрибут `src="assets/img/logo.svg"` на `src="assets/img/logo.png"` (проще всего — глобальный поиск-замена по всем файлам в редакторе).
4. Фавикон (иконка вкладки браузера) сейчас генерируется прямо в коде страницы (буква «B» в SVG внутри `<link rel="icon" href="data:image/svg+xml,...">` в `<head>`) — при желании замените на свой файл `favicon.ico` и пропишите `<link rel="icon" href="favicon.ico">`.

## Деплой

### Вариант 1. Ручная загрузка на любой хостинг (FTP)

1. Скачайте/скопируйте всю папку проекта целиком (включая `assets/`).
2. Подключитесь к хостингу по FTP (например, через FileZilla) или через файловый менеджер в панели хостинга.
3. Загрузите содержимое папки в корневую директорию сайта (обычно называется `public_html`, `www` или `htdocs`).
4. Откройте домен в браузере — сайт должен заработать сразу, никакой дополнительной настройки сервера не требуется (это статические файлы).
5. Если сайт должен открываться из подпапки (например, `сайт.by/basslight/`) — ничего менять не нужно, все ссылки относительные и сработают сами.

### Вариант 2. GitHub Pages

1. Создайте новый репозиторий на [github.com](https://github.com) и загрузите туда все файлы проекта (через веб-интерфейс «Add file → Upload files» или через `git push`, если знаком с git).
2. В репозитории уже лежит готовый файл `.github/workflows/deploy.yml` — он автоматически публикует сайт при каждом пуше в ветку `main`.
3. Зайдите в репозитории в **Settings → Pages** и в разделе **Build and deployment → Source** выберите **GitHub Actions** (не «Deploy from a branch»).
4. Сделайте любой коммит в ветку `main` (или запустите workflow вручную во вкладке **Actions**) — через 1–2 минуты сайт появится по адресу вида `https://имя-пользователя.github.io/имя-репозитория/`.

### Вариант 3. Netlify

1. Зарегистрируйтесь на [netlify.com](https://netlify.com).
2. Нажмите **Add new site → Import an existing project** и подключите ваш GitHub-репозиторий (или перетащите папку проекта прямо в браузер через **Deploy manually** — сайт опубликуется без всякого git).
3. Настройки сборки Netlify подхватит автоматически из файла `netlify.toml` (папка публикации — корень проекта, команда сборки не нужна).
4. После первого деплоя Netlify выдаст адрес вида `https://случайное-имя.netlify.app` — его можно переименовать в настройках или привязать свой домен (**Domain settings → Add custom domain**).

## Технические детали

- **Палитра** задаётся CSS-переменными в начале `assets/css/style.css` (`--graphite-900`, `--terracotta`, `--amber` и т.д.) — поменяв значения там, вы измените цвета сразу на всём сайте.
- **Шрифты** — Google Fonts Unbounded (заголовки) и Golos Text (текст), подключены с поддержкой кириллицы через `<link>` в `<head>` каждой страницы.
- **Адаптивность** проверена на ширинах 360 / 768 / 1024 / 1440px, брейкпоинты заданы в медиа-запросах в `style.css`.
- **Формат отправки заявки**: см. раздел «Как редактировать тексты и телефоны» выше.
- Аналитика по умолчанию не подключена — сайт не отправляет никаких данных на сторонние серверы, кроме шрифтов Google Fonts и (в режиме `formspree`) самого Formspree.
